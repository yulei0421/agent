# Agent 研究能力与运行治理设计

## 目标

在保持无状态、只读和公开数据边界的前提下，扩展金融 Agent 的数据工具、决策质量、研究输出和交付治理。每项能力均可独立测试，且不引入账户、交易、付费数据源、服务端持久化记忆或跨设备会话。

## 工具与数据边界

ToolManifest 新增两个部署期固定、`read_only` 工具：

- `get_technical_indicators`：从允许的市场网关取得固定的日线/月窗口，在服务端计算 SMA14 与 RSI14；模型不能自选时间窗口、指标公式或上游 URL。
- `get_economic_calendar`：仅请求固定的公开周度日历 JSON 源；网关对请求和 JSON 读取统一施加超时、转发取消，并只发布已校验的时间、国家、标题、影响等级和数值字段。

所有工具继续使用闭合 schema、10 秒 manifest 时限、子 AbortSignal、输出字段白名单和 URL/IP 清洗。新增工具不具有写操作，不需要审批节点。

## 决策与并行工具执行

LangGraph 在每轮工具执行后产生服务端派生的摘要，仅包含调用数、失败数、陈旧数、结果类别和新鲜度状态，不包含原始工具内容。下一次模型请求使用该摘要避免盲目重试；当一整轮连续失败达到两轮，或发现只有陈旧数据且没有可继续执行的工具时，图强制进入无工具最终回答。

同一轮的合法工具调用并行启动，以缩短多资产研究延迟；对浏览器 SSE 和后续模型消息仍严格按模型原始调用顺序发布。任一调用的取消结果终止请求，三轮和六次总上限不变。

## 结构化研究输出

金融工作台请求会附带受限 `financial_research` 输出模式。服务端仅在已验证金融上下文存在时追加不可由客户端伪造的 JSON 输出契约。模型最终输出必须满足：标题、结论、至多六项证据、至多六项风险及可选数据时间。

浏览器只解析具备普通对象原型、长度与 ISO 时间限制的 JSON；未知字段被丢弃，格式不合法则降级为原始 Markdown。已验证报告以结论、依据、风险与数据时间卡片呈现，工具结果仍独立展示。

## 观测与交付

`InstrumentedToolExecutor` 在工具端口外统一记录固定工具名、成功/失败、延迟桶、来源最近状态与新鲜度状态。指标标签集合固定，绝不记录用户文本、参数、URL、IP、密钥或原始工具结果。`AppModule` 只将已清洗的注册表结果交给该包装器。

CI 执行 `pnpm typecheck`、`pnpm test` 与 `pnpm build`。本地性能基线用无网络的模拟流验证首事件和完整运行延迟；`pnpm test:smoke` 在未设置 `SMOKE_BASE_URL` 时跳过，设置后只检查目标部署的 health 端点。

## 验收

- 六个 ToolManifest 固定发布，技术指标和经济日历均经过取消、超时、净化与 schema 回归覆盖。
- 并行工具调用保持模型顺序；失败/陈旧决策不会导致无限工具循环。
- 金融工作台可安全渲染合格研究报告，普通聊天不强制 JSON。
- Prometheus 指标包含固定工具维度、延迟、新鲜度和来源状态，不泄露调用内容。
- 类型检查、完整测试集、生产构建和 diff 校验均通过。
