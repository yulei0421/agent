# Agent 能力矩阵

更新时间：2026-08-31

## 当前已具备

| 能力 | 当前实现 | 状态 |
| --- | --- | --- |
| 模型自主工具选择 | 固定 ToolManifest、闭合 schema、服务端校验和执行 | 已接入 |
| 目标拆解与自主循环 | LangGraph Planner、当前步骤、工具轮次和安全上限 | 已接入 |
| 计划透明度 | `plan` SSE 快照、步骤状态卡片、本地消息保存 | 本次接入 |
| 流式交互 | SSE 增量、推理提示、工具事件、打字机、停止生成 | 已接入 |
| 失败恢复 | 模型重试/熔断、工具超时/取消、失败回答本地重新生成 | 本次接入 |
| 轻量文档输入 | 浏览器读取 TXT/MD/CSV/JSON；PDF/图片经服务端 PDF.js 文本提取或 Tesseract.js OCR 后作为受限上下文发送 | 本次接入 |
| 外部数据边界 | 固定供应商、结果清洗、时间新鲜度、URL/IP 防护 | 已接入 |
| 金融研究产物 | 结构化研究报告、PDF、可编辑 PPTX | 已接入 |
| 本地会话体验 | IndexedDB 会话、离线队列、WebSocket 状态 | 已接入 |
| 本地工作记忆 | 会话完成后生成有上限的本地摘要，并在下一轮作为参考上下文恢复 | 本次接入 |
| 文档检索 | 浏览器先做本地分片召回，服务端再以 token-count 向量和 cosine similarity 做请求级排序，不建立持久索引 | 本次接入 |
| 运行观测 | 请求 ID、Prometheus 聚合指标、工具/模型遥测 | 已接入 |
| 健康优先模型路由 | 可选备用 OpenAI 兼容模型；主模型零输出失败才切换；切换次数指标 | 本次接入 |
| 引用账本校验 | 从本次成功工具结果收集安全来源 ID，结构化报告拒绝未知来源 | 本次接入 |
| 受限多 Agent 协作 | 金融研究模式并行运行研究员和风险复核员，只产出不可信规划提示，由主 Graph 统一调用工具 | 本次接入 |
| 工具执行前人工确认 | 显式 `review=true` 时，SSE 发审批事件并暂停工具；独立 API 可批准/拒绝，过期和断开自动拒绝 | 本次接入 |
| 能力发现 | 固定 `CapabilityManifest`，通过 `GET /api/capabilities` 提供脱敏版本、风险、预算和任务类型 | 本次接入 |
| 能力清单 UI | 前端读取公开 manifest，在侧栏展示工具、子 Agent 和模型类别及描述 | 本次接入 |
| 任务级模型路由 | `fast`、`reasoning`、`structured` 固定路由；专用槽位未配置时回退默认模型，并保留健康故障切换 | 本次接入 |
| 受限子 Agent 注册表 | 研究员和风险复核员由服务端注册表声明，角色级超时、输出条数和并发边界，失败隔离 | 本次接入 |
| 文档摘要边界 | 文本摘要和 PDF/图片 base64 均经服务端二次校验；原始二进制只在请求内存中处理 | 本次接入 |
| 引用新鲜度 | 引用账本记录来源、观测时间、`fresh/stale/unknown` 和过期标记，并保存到本地消息 | 本次接入 |
| 临时任务运行时 | SSE 首事件返回随机任务 ID，支持进程内状态查询、取消、TTL 和事件计数 | 本次接入 |
| SSE 长连接保活 | 服务端发送注释型 keep-alive 帧，代理空闲超时不会误断开，结束/取消时自动清理 | 本次接入 |

## 仍缺少的能力

以下能力是研究型 Agent 常见的扩展方向，但当前没有偷偷开启：

| 优先级 | 缺口 | 当前原因 | 接入前置 |
| --- | --- | --- | --- |
| P1 | 用户可编辑计划、步骤确认和跨请求暂停恢复 | 当前仅支持工具调用前审批；计划仍由服务端生成且状态随单次请求结束 | 服务端 checkpoint、会话归属和权限模型 |
| P2 | 文档病毒扫描与跨请求语义索引 | 当前已接入受限 PDF/图片 OCR 和请求级向量召回，但未做病毒扫描、跨请求索引或持久化 | 扫描服务、数据保留、权限与索引生命周期 |
| P1 | 连接器/MCP 外部应用 | 当前工具清单为部署期固定六项 | OAuth、权限范围、租户隔离和审计 |
| P2 | 持久后台长任务、定时任务和通知 | 当前仅有进程内临时任务，SSE 断开或服务重启后不可恢复 | 任务队列、任务状态存储、重试和通知通道 |
| P2 | 浏览器/计算机操作 | 当前工具只读且不执行任意网页动作 | 沙箱、域名白名单、人工确认和操作回放 |
| P2 | 动态多 Agent 跨任务协作 | 已接入固定角色、角色级预算和失败隔离；尚未支持跨任务共享上下文或用户自定义角色 | 子 Agent 协议、共享上下文和权限模型 |
| P2 | 来源代理与过期重验证 | 已接入本次请求内的安全引用账本、新鲜度和未知来源拒绝；尚未提供原始来源快照或用户可打开的代理页 | 安全引用代理、来源快照和过期策略 |
| P2 | 成本/能力模型路由 | 已接入固定任务类型路由和健康故障切换；尚未根据实时成本、配额或供应商能力自动优化 | 供应商能力声明、成本策略、配额和结构化输出兼容性 |

## 接入原则

1. 先接入不改变现有无账户、无服务端持久化和只读金融工具边界的能力。
2. 涉及权限、文件、外部连接器、浏览器动作或后台任务时，先写清数据保留、取消、审计和人工确认规则。
3. 每个能力必须同时具备端到端测试、失败路径和可观测字段，不能只增加 UI 开关。
4. 交易执行、资金操作和绕过工具白名单不属于本项目的 Agent 能力路线。
